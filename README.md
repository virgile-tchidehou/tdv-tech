# 📖 Overview

This repository contains the source code of my personal engineering portfolio.

The website presents my background, technical expertise and engineering projects with a strong focus on **Embedded Systems**, **Internet of Things (IoT)**, **Robotics**, and **Cyber-Physical Systems**.

More than a personal website, this portfolio is designed to serve as a professional showcase for universities, recruiters and collaborators interested in my work.

---

# 🎯 Objectives

The portfolio aims to:

- Present my engineering profile
- Showcase selected projects
- Highlight technical skills
- Share my learning journey
- Provide easy access to my GitHub repositories
- Offer recruiters and universities a clear overview of my work
